# Image provenance

The README and screen gallery use one actual hardware photograph: `Images/Waveshare-device.jpg`, supplied by the owner as `IMG_3524.HEIC`. It was converted to JPEG and metadata was removed. The photographed device and display have not been generated or retouched. Its visible seed is public and must never be used for funds.

All other Waveshare interface images are exact captures of the production UI running in the native test harness, with public deterministic fixtures. See [the gallery](screenshots.md) and [the source/pixel hashes](screenshot-provenance.json). The original comparison panels use pinned BitMaker v2.2.0 code at `ba6e9ebe226222cbb04415a635a934eeae372dab`.

No AI-generated device render, photo composite or additional hardware photo is used in the published presentation. The original BitMaker cover and existing StickS3 screenshots remain in their respective documentation.
